# Reel build (2.5D HyperFrames)

Load the global `/hyperframes-core` skill when you need composition rules, `gsap-timeline` /
`gsap-core` (in this folder) for easing and timeline mechanics, and `motionmaxxing` references
(`references/motion.md`, `transitions.md`, `type.md`) for craft. Owner rules in `rules/` win.

## Files in a reel
- `template.tpl`: the composition you edit (shots live in `build()`).
- `index.html`: GENERATED by `python engine/tools/captions.py <reel>`. Never edit it.
- `lib/stage3d.js`, `lib/captions.js`, `lib/brand-models.js`: copied from `engine/lib` at scaffold.
- `assets/models/*.fbx`, `assets/sfx/*.mp3`: hard links to the shared library.
- Reference build: `engine/examples/page-speed.template.tpl` (16 shots, 3 worlds, 4 counters,
  live CanvasTexture screens, micro-gags). Copy patterns from it.

## Captions
1. `python engine/tools/vo.py <reel> words` lists word indexes and original start times.
2. Write `captions.json` (UTF-8 file, never shell): `merge` maps spoken number words to digits
   (`"38": ["10,000", 39]`), `chunks` are `[first, last, [highlight words as displayed]]`, one
   green word each, <= 2 lines.
3. `python engine/tools/captions.py <reel>` refuses gaps/overlaps and writes index.html.

## Shots
- Times in `template.tpl` are ORIGINAL VO seconds; `at(t)` and `T(d)` convert for the speed.
- `createStage({ canvas, models: [...], fix })` loads and recolours models; list every model used.
  Find models: `python engine/tools/models.py search <word>`; fetch: `models.py fetch <name>`, then
  `models.py link <reel>`.
- `S.inst(name, { x, y, z, s, o, float })` places a copy; animate `it.st` with GSAP.
- Helpers: `world(t, color)`, `show(it, t, from, to, d, ease)`, `hide(it, t, to, d)`,
  `big(sel, t0, t1)` (full-screen type/number), `count(sel, t0, d, from, to, fmt)`, `squash(it, t)`,
  `shake(it, t)`. Camera: tween `S.cam` (`x, y, z, rx, ry, rz`; `S.CZ` is the rest distance).
- Screens: `S.board(w, h)` + `S.screenPlane(tex, w, h)` added to a model's group; redraw in a
  `S.hooks.push((t) => ...)` callback.
- Change something every 1.5-2.5 s; frame 1 moves; the last frame equals the first.
- Keep everything out of the caption zone y 1180-1440 (objects end above y ~1140).

## Check loop (after every edit)
```bash
python engine/tools/captions.py <reel>
cd reels/<reel> && npm run check
npx --yes hyperframes@0.8.152 snapshot -o snap --at 0.3,<one time per beat> --no-end --describe false --timeout 60000
```
Look at `snap/contact-sheet.jpg` and the full-size frames for every beat before rendering. For
key actions, snapshot at 0.05 s steps across 0.3 s and check anticipation / squash / follow-through.
