# Script rules

The full method is `.claude/skills/reel-script/SKILL.md`. These are the non-negotiables.

## Shape (35-45 s spoken before speed-up, ~80-105 words; Gulf VO runs 2.2-2.4 words/s)
| beat | job |
|---|---|
| HOOK 0-3 s | strongest number or story, or a question about something the viewer knows by name. Key word in the first three words. 8 words max. |
| ONE ANALOGY <= 8 s | one Gulf daily-life situation (restaurant, tailor, generator, delivery driver). Usually the World C scene. |
| NAME IT | «وهذا اللي نسميه ...» with the English term on screen. |
| PROOF | the real story or number, exact, with currency; key numbers become full-screen counters. |
| TWIST at 60-70% | «بس في شي أغلب الناس ما يعرفونه»: where it hurts a Fortune Code client. |
| FORTUNE CODE + ASK, last 5-8 s | one sentence about Fortune Code, then a comment-keyword CTA: «اكتب "كلمة" في الكومنتات ونـ...». |
| LOOP | the last line echoes the hook so the replay reads as one sentence. |

## Language
- Light Gulf Arabic everyone understands: وش، تدري، تبي، زين، سوّى، محد، مو، يطيح. Never Egyptian.
  (TikTok photo slideshows are the exception: formal MSA. Reels are Gulf.)
- Humanize pass: no em dashes, no ellipsis characters, no invisible Unicode, no «ليس فقط... بل»,
  no adjective triads, no one-word rhetorical lines («والحل؟»), no stock phrases
  («في عالمنا المتسارع»، «الحل الأمثل»، «نقلة نوعية»، «لا تفوّت الفرصة»).
- Never «الأفضل»، «ثوري»، «سريع وسهل». Never name competitors.
- The AI customer-service product is «موظفك الذكي», never «شات بوت».
- Fortune Code does not build on Salla or Zid; e-commerce is custom-built.
- Never «تابعنا» or «الرابط في البايو». The ask is one typeable keyword.
- One idea per reel. Two ideas = two reels.
- Never repeat a topic in `memory/REELS_LOG.md`.

## Hooks
Write three from different formulas, score each 0-100 on FRONTLOAD, SPECIFICITY, STAKES, ADDRESS,
BREVITY, show the table, pick one. Under 50 = no hook yet. Dealbreakers: a greeting,
«في هذا الفيديو», «استنى لا تسكرول», a vague promise. Formulas and evidence: `memory/EVIDENCE.md`.

## Facts
See `rules/facts.md`. Nothing goes in a script that was not verified on a page actually opened.

## CTA promises
A keyword CTA is a promise the team must keep («نفحص لك سرعة موقعك ببلاش»). Flag every promise to
the owner on delivery; if he has not approved it before, say so.

## The 3 loops (thewolfofmarketingstreet, owner reference 2026-11-06)
Loops matter more than structure. Every reel script marks all three:
1. **Hook loop (0-5 s):** open a question the viewer needs answered.
2. **Intensifier loop (about 5-15 s):** make the open question impossible to ignore, with higher stakes,
   a surprising number, or "and it gets worse".
3. **Rehook loop (mid-video, about 40-60 % in):** open a new question before the first one closes,
   so retention does not drop in the middle.
Close the loops in order. The payoff and the CTA come after the last loop closes.

## Triple hook (kallawaymarketing, owner reference 2026-11-06)
The first 1-2 sentences carry three steps:
1. **Context, immediately:** the topic is clear from the first words, said in the voice, shown in the
   visual and written on screen. Delaying the context even to the second half of the sentence raises skips.
2. **Lean:** a stat, a pain, a wanted benefit or something unexpected, so the viewer leans in.
3. **Contrarian snapback:** yank them the other way («بس المشكلة مو في التصميم…»). This is what holds the scroll.
Read the first two sentences alone. If the context is unclear or nothing pulls, rewrite them.

## Default service-reel formula (learned from ROAR, details in knowledge/content-engine/10-script-patterns.md)
One service × one buyer situation. 75-90 words, 33-38 s, about 2.3 words a second, Gulf dialect, second person until the turn.
1. Hook in the buyer's situation («إذا…» / «ناوي…» / «تبي…؟» / «أنت … مو …» / «بسألك سؤال…»).
2. Snapback: «لا تدور على X. دور على Y.» or «ما نسوي X وخلاص.»
3. Pain as one concrete picture.
4. Turn: «في فورتشن كود نبدأ من…».
5. Diagnostic questions in the customer's words («وش…؟ وين…؟ مين…؟»).
6. Method as a 3-5 beat list + proof (verb triplet or a real number from FACTS, then «لكن…»), tricolon or outcome line.
7. CTA = qualifier («إذا عندك…») + ONE fixed action, the same in every reel + outcome («وخلّ فورتشن كود…»).
Second format for trial variants: the xx call-and-response («X؟ نسوي.» ×2 → bad version «ما نسوي» → great version «نسوي» → question + tagline), 12-15 s.
