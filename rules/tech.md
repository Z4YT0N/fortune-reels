# Technical rules and known traps

## HyperFrames (pinned 0.8.152 in every reel's package.json)
- One root `index.html` per reel. It is GENERATED by `captions.py` from `template.tpl`; edit the
  template, never index.html. Other HTML-like files must not end in .html (`.tpl`), or check fails
  with `multiple_root_compositions`.
- `<html dir="rtl">` renders a blank video. Put `direction: rtl` on the text containers.
- Every `<audio>` needs an id; tracks must not overlap. The reel plays one track: mix.mp3.
- Determinism: no `Date.now()`, no `Math.random()` (use `hash(n)`), no network at render time
  except the pinned CDN scripts. The three.js build is awaited through
  `window.__hf.buildReady["main-3d"] = build()`; draw on the timeline's onUpdate and on `hf-seek`.
- Module imports in a composition are relative: `./lib/stage3d.js`, never `lib/...`.
- Canvas text needs its fonts preloaded (`document.fonts.load`) or it falls back to a serif.
- Gates: `npm run check` after every template edit; `npx --yes hyperframes@0.8.152 snapshot -o snap
  --at <t,...> --no-end --describe false --timeout 60000` for stills; `npm run render` for the MP4.
- Upgrading HyperFrames: `npx hyperframes@latest upgrade --project . --check` inside one reel,
  render it, compare, then change `HF` in `engine/tools/common.py`. Never upgrade mid-reel.

## three.js / 3D
- Models come from 3dicons (`engine/tools/models.py search|fetch`). Free, CC0.
- `wifi` renders nothing; use another model. Test every new model on a sheet first.
- Per-model colour fixes live in `DEFAULT_FIX` (engine) or the reel's `fix` option.
- GSAP: animate plain state objects (`it.st`), not SVG transform attributes read back as x/y.
- To hide something for good, move it off frame AND set `o: 0`.

## Arabic
- Arabic never goes through shell arguments (it turns into ؟؟؟). Write it into a UTF-8 file
  (script.txt, captions.json, the template) and let the tools read the file.
- Lottie/After Effects text from templates breaks Arabic joining in lottie-web. If an AE template is
  needed, drive After Effects itself (see the fortune-next memory note `envato-ae-templates`).

## Secrets
- ElevenLabs key is read by `common.secret()` from the environment, `fortune-reels/.env` or
  `fortune-next/.env.local`. Never print it, never commit `.env`.
