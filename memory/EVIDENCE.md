# Evidence: what actually brings views and leads for Fortune Code

## Own history (analysis 2026-10-20, fortune-next memory `sales-drop-root-cause-2026-10`)
- Demand came from ORGANIC viral reels, not ads (no ads before Oct 2026).
- Viral reels: IG 2025-10-15 (402k), IG 2025-12-08 (327k), 2026-01-29 (731k IG / 397k TikTok,
  meme hook «العميل: احنا طلبنا موقع مش برزنتيشن» + a 3D website showcase).
- WhatsApp chats followed the virals: Dec 121, Feb 177, then 20-38/month when posting stopped.
- Posts since Aug 2026 were plain mockup showcases with no relatable hook: median 250-700 views.
  The viral clip reposted WITHOUT its meme hook got 0.6-1.9k plays. The hook is the asset.
- Takeaway: hook-first (meme / POV / surprising number) + a premium visual payoff. Cadence matters:
  the leads stopped when posting stopped.
